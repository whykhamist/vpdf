# @vpdf/playground

Private local harness for `@whykhamist/vpdf` and the opt-in plugins. Not published to npm.

From the repo root:

```bash
npm install
npm run dev
```

Vite serves the app at http://localhost:5173.

The playground depends on the workspace packages (`@whykhamist/vpdf` and the plugin packages). Build those first if you need production artifacts (`npm run build` from the repo root).
